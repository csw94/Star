# 별빛 결계의 수호자 (Chronicles of Pixel)

Pygame CE로 만든 한글 2D 탑뷰 RPG입니다. 거점 마을 오크밸리를 중심으로 동·서·남·북
네 방면의 필드와 제단 던전을 탐험하고, 별빛 결계를 되살리세요.

이 저장소는 **실행 파일 배포용**입니다. 소스 코드는 포함되어 있지 않습니다.

## 다운로드 및 실행 (Windows)

1. [최신 릴리즈 페이지](https://github.com/csw94/Star/releases/latest)를 엽니다.
2. Assets에서 **ChroniclesOfPixel.exe**를 내려받습니다.
3. 내려받은 파일을 더블 클릭해 실행합니다. Python 설치는 필요하지 않습니다.

세이브 데이터는 Windows 사용자 앱 데이터 폴더에 저장되므로, 새 버전 EXE로 바꿔도
기존 모험을 이어서 할 수 있습니다.

> Windows SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

## 기본 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| SPACE / Enter / Z | 대화·조사·선택 |
| I 또는 Tab | 상태 화면 |
| B | 가방 |
| O | 설정 |
| M | 소리 켜기/끄기 |
| F5 | 저장 |
| ESC | 저장 후 타이틀로 |

## 버전별 변경 사항

각 [릴리즈](https://github.com/csw94/Star/releases) 노트를 확인하세요.
